# Templates RH — documentos assináveis

PDFs em branco usados como referência para upload/admissão:

| Arquivo | Tipo no sistema |
|---------|-----------------|
| `termo-reconhecimento-ciencia.pdf` | Termo de Reconhecimento e Ciência |
| `recibo-vale-refeicao.pdf` | Recibo / Ajuda de Custo – Vale Refeição |

Os arquivos `*-original.pdf` são as versões enviadas pelo cliente antes da centralização da linha de assinatura.

Fluxo: RH faz upload do PDF preenchido em **Documentos Admissionais**; o colaborador assina no PWA (mesmo fluxo dos certificados).
